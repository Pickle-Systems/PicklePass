04 / Frequently asked questions

About PicklePass.

Common questions about this Windows password manager.

What is PicklePass?

PicklePass is a password manager for Windows 64-bit designed to organize saved credentials in a focused desktop application.

Does PicklePass support TOTP?

Yes. PicklePass supports time-based one-time password (TOTP) authentication codes alongside account information.

How do I download PicklePass?

Download the latest available Windows 64-bit standalone ZIP package from the official PicklePass GitHub Releases page.

Is PicklePass open source?

PicklePass is published under the GNU General Public License version 3 (GPLv3), and its source code is available on GitHub.
